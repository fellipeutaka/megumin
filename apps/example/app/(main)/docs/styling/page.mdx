# Styling

Sileo keeps its original gooey SVG and spring animations. The Base UI data model
is used for lifecycle, while `data` carries the small set of Sileo visual
customizations.

## Fill Color

Set `data.fill` to change the SVG background. The original Sileo defaults are
`#1a1a1a` for the light theme and `#f2f2f2` for the dark theme.

## Roundness

Set `data.roundness` to tune the SVG blur radius and the pill's corners.

<CodePreview
	actions={[
		{ label: "Sharp (12)", id: "roundness-sharp" },
		{ label: "Round (16)", id: "roundness-round" },
	]}
	code={roundnessCode}
/>

> **Performance note:** Higher `roundness` values increase the SVG blur radius used for the gooey morph effect, which is more expensive to render. The recommended value is `16` for a good balance between aesthetics and performance.

## Global Defaults

Use Base UI's provider for shared lifecycle defaults and `Toaster` data attributes
for the Sileo viewport.

```tsx
<Toast.Provider timeout={6000} limit={5}>
  <Toaster data-position="top-right" data-theme="dark" />
  <App />
</Toast.Provider>
```

## CSS Variables

Sileo exposes CSS custom properties you can override globally to change state
colors, dimensions, or animation timing.

```css
:root {
  /* State colors (oklch) */
  --sileo-state-success: oklch(0.723 0.219 142.136);
  --sileo-state-loading: oklch(0.556 0 0);
  --sileo-state-error: oklch(0.637 0.237 25.331);
  --sileo-state-warning: oklch(0.795 0.184 86.047);
  --sileo-state-info: oklch(0.685 0.169 237.323);
  --sileo-state-action: oklch(0.623 0.214 259.815);

  /* Dimensions */
  --sileo-width: 350px;
  --sileo-height: 40px;

  /* Animation */
  --sileo-duration: 600ms;
}
```

For example, to make all success toasts use a custom brand color:

```css
:root {
  --sileo-state-success: oklch(0.7 0.2 200);
}
```
