# Getting Started

Sileo is a tiny, opinionated toast component for React. It uses gooey SVG morphing and spring physics to create buttery smooth notifications — beautiful by default, no configuration required.

## Installation

```bash
npm install sileo
```

## Quick Setup

Add a Base UI `Toast.Provider` and the Sileo `Toaster` to your app's root layout.
Use `Toast.useToastManager()` from a descendant component to create toasts.

```tsx
import { Toast, Toaster } from "sileo";

export default function App() {
  return (
    <Toast.Provider>
      <Toaster data-position="top-right" />
      <YourApp />
    </Toast.Provider>
  );
}
```

## Positions

Set the viewport position with the Sileo `data-position` attribute. The viewport
supports all six original Sileo positions, and the toast pill automatically
aligns with the selected edge.

```tsx
<Toaster data-position="bottom-center" />
```

Available positions: `top-left`, `top-center`, `top-right`, `bottom-left`, `bottom-center`, `bottom-right`.
